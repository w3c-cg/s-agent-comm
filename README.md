# Semantic Agent Communication Community Group

This repository is the governance and coordination entry point for the
[Semantic Agent Communication Community Group](https://www.w3.org/community/s-agent-comm/)
at W3C. It hosts the adopted [Charter](https://w3c-cg.github.io/s-agent-comm/), the
group's Notes, and coordination material.

## The group

- Group page, membership and joining: <https://www.w3.org/community/s-agent-comm/>
- Mailing list: [public-s-agent-comm@w3.org](mailto:public-s-agent-comm@w3.org),
  [archives](https://lists.w3.org/Archives/Public/public-s-agent-comm/)
- Chair: Melvin Carvalho (from November 2026)
- Code of conduct: [W3C Code of Conduct](https://www.w3.org/policies/code-of-conduct/)
  and this repository's [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

The [Charter](https://w3c-cg.github.io/s-agent-comm/) was adopted by Community Group

## Technical work

Specifications, ontologies and supporting artifacts are developed in the
[s-agent-comm](https://github.com/s-agent-comm/) GitHub organisation:

| Repository | What it holds |
|---|---|
| [agent-ontology](https://github.com/s-agent-comm/agent-ontology) | The Semantic Agent Communication Ontology |
| [agent-idl](https://github.com/s-agent-comm/agent-idl) | AgentIDL, an extension of WebIDL for semantic agent communication |
| [agent-credential](https://github.com/s-agent-comm/agent-credential) | A Verifiable Credentials schema for an agent's identity, capabilities, delegations and execution rights |
| [usecases](https://github.com/s-agent-comm/usecases) | Use cases, one folder per case; contributions welcome |
| [w3id.org](https://github.com/s-agent-comm/w3id.org) | Persistent identifiers for the group's vocabularies |
| [s-agent-comm.github.io](https://github.com/s-agent-comm/s-agent-comm.github.io) | The organisation's website |

## Roles of the two places

This repository (`w3c-cg/s-agent-comm`) holds governance: the Charter, the Notes,
process and coordination documents.

The technical repositories under `s-agent-comm` hold the specifications, the ontology
and schema design, and validation artifacts and examples. The separation keeps
governance stable while technical work evolves in its own repositories.

## Participation

Anyone may [join the group](https://www.w3.org/community/s-agent-comm/) under the
[W3C Community and Business Group Process](https://www.w3.org/community/about/process/).
Discussion happens on the [mailing list](https://lists.w3.org/Archives/Public/public-s-agent-comm/);
issues and pull requests go to the relevant repository under the
[s-agent-comm](https://github.com/s-agent-comm/) organisation, following
[CONTRIBUTING.md](CONTRIBUTING.md).
